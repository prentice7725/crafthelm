# CraftHelm Learn Skill

1. Classify failure causes using standard categories (`TEST_FAILURE`, `SCOPE_VIOLATION`, `SOT_CONFLICT`, etc.).
2. Propose new reliability rules in `proposed`/`observe` status first.
3. Never auto-weaken acceptance criteria or promote rules to `enforce` without evaluation and human approval.
