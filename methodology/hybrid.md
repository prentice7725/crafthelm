# Hybrid & Composable Methodology

CraftHelm은 `lifecycle × specification × engineering × execution` 4축을 독립 조합한다.

- `waterfall + sdd + tdd + stage`: 엄격한 고객 프로젝트
- `iterative + lightweight + tdd + full`: 빠른 기능 반복(단, 최종 인수는 여전히 사람 결정 필수)
- `incremental + existing + characterization_first + full`: 레거시 유지보수 및 안전한 리팩터링
- `docs` / `research`: 코드 변경이 없을 때 RED 테스트를 강제하지 않고 링크·출처·스키마 계약을 사용한다.
