# Hybrid & Composable Methodology

CraftHelm은 `lifecycle`, `specification`, `engineering`, `execution` 네 설정을 독립으로 조합한다.

- `waterfall + sdd + tdd + stage`: 단계별 승인이 필요한 엄격한 프로젝트에 쓴다.
- `iterative + lightweight + tdd + full`: 빠른 기능 반복에 쓰되 최종 인수는 여전히 사람이 결정한다.
- `incremental + existing + characterization_first + full`: 레거시 유지보수와 안전한 리팩터링에 쓴다.
- `docs` 또는 `research`: 코드 변경이 없을 때 RED 테스트를 강제하지 않고 링크·출처·스키마 계약을 적용한다.
